# PowerBI / Dashboard

**RESPONSABIL:** Membrul 4 (Reporting Developer)

Aici se pune fișierul `Dashboard.pbix` (Power BI Desktop) — nu poate fi generat automat, trebuie construit direct în aplicație.

## Ce ar trebui să conțină dashboard-ul (minim):
- Conectare la baza de date SQL Server (`ETL_Assignment`), pe view-urile sau tabelele din schema `dwh`
- Un grafic cu activitatea lunară pe tip (Working / Absence / Training / Exam)
- Un filtru/slicer pe angajat și pe lună
- Total ore lucrate per proiect

Această parte e **bonus** conform cerinței temei — dacă timpul e limitat, priorizați scripturile SQL și rapoartele din `Reports/` înaintea dashboard-ului.
